# A 股多系统选股筛选器

单文件 Python 选股筛选器，实现 5 套技术面选股系统，一次运行输出全部结果（HTML 报表）。

## 5 套系统

| 系统 | 逻辑 | 输出 |
| --- | --- | --- |
| 洗盘回踩 | 非 ST、剔除北交所、流通市值 100—300 亿、近 20 日出现过涨停、今日收阴线且缩量、收盘价靠近 10 日均线（±3%）、MA10 向上 | 全部 |
| 放量突破 | 涨幅 3%—5%、量比 > 1、换手 5%—10%、流通市值 50—200 亿、成交量持续放大、上方无压力、分时价 > 成交均价 | 全部 |
| 洗盘回踩（最优） | 同系统一，只保留评分最高一只 | 1 只 |
| 放量突破（最优） | 同系统二，只保留评分最高一只 | 1 只 |
| 强势多头突破 | 涨幅 3%—5%、量比 > 1.5、换手 5%—10%、当日量 > 前 5 日均量 1.5 倍、距 20 日高 ≤ 3% 且上方无放量滞涨、MA5 > MA10 > MA20、收盘位于全天振幅上方 70%、所属板块强于大盘 | 全部 |

## 设计要点

- **单文件零配置**：一个 `.py` 跑完，无外部配置文件
- **并发取数**：`ThreadPoolExecutor` 多线程抓取行情，配 UA 轮换与重试
- **指标计算**：均线（MA5/MA10/MA20）、量比、换手率、涨停判断、套牢区判定全部在脚本内实现
- **评分排序**：最优系统按综合评分取第一名，评分权重在脚本内显式定义
- **HTML 报表输出**：结果直接渲染为自包含 HTML，含筛选条件说明与明细表

## 快速开始

```bash
pip install pandas certifi

python screeners.py
```

输出文件默认写到 `~/Downloads/股票筛选/杨总精选_YYYYMMDD_HHMMSS.html`，可在脚本内 `OUTPUT_DIR` 修改。

> 数据来自公开行情接口，仅供学习研究，不构成投资建议。
